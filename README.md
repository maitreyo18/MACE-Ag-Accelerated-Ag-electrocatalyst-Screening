# MACE-Ag-Accelerated-Ag-electrocatalyst-Screening

This repository contains model checkpoints, datasets, scripts, and relaxed structures associated with our data-driven study of Ag-alloyed electrocatalysts for the oxygen reduction reaction (ORR). We trained a scratch-trained MACE interatomic potential, referred to as **MACE-Ag**, trained on high-throughput DFT data for Ag-based surface alloys with *O and *OH adsorbates across multiple coverages. The workflow enables rapid screening of alloy stability, adsorbate-induced surface rumpling, and global minimum adsorption energetics, reducing the need for exhaustive DFT relaxations across the large Ag-alloy configurational space. This repository contains the model checkpoints, the train/val/test data of structures, energies, and forces and the DFT-relaxed configurations reported in the literature.

Using this MLIP-accelerated framework, we identify dilute Ag–Pd alloys with ORR activity comparable to Pt at low coverage, while ternary Ag–Au–Cu and Ag–Cu–Pd compositions show improved activity over pristine Ag at higher coverage. The repository is intended to support reproducibility and future studies on MLIP-driven catalyst discovery, Ag-based surface alloys, and coverage-dependent ORR thermodynamics.
